# 小悪魔レベルBOT v5

## 追加内容

- SQLite保存
- 旧 `data/data.json` からSQLiteへ自動移行
- WALモードによる壊れにくい保存
- Windowsログイン時の完全自動起動
- BOT停止時の10秒後自動再起動
- ログを `logs/bot.log` に保存
- discord.jsのready警告を修正

## 初回セットアップ

1. ZIPを「すべて展開」
2. `FIRST_SETUP.bat` を実行
3. `.env` を設定
4. `BOT_DEBUG.bat` で一度起動確認
5. 正常にログインできたら `WINDOWS自動起動を登録.bat` を実行

## SQLiteデータ

データは以下に保存されます。

```text
data/koakuma-level.db
```

SQLiteはNode.js v24内蔵の `node:sqlite` を使うため、
追加のSQLiteパッケージは不要です。

以前のJSONデータが同じフォルダの `data/data.json` にある場合、
初回起動時に自動でSQLiteへ移行します。

## Windows自動起動

`WINDOWS自動起動を登録.bat` を実行してください。

登録後は以下の動作になります。

- Windowsへログインすると自動起動
- 黒い画面を表示せずバックグラウンド起動
- BOTが停止した場合は10秒後に再起動
- ログは `logs/bot.log` に記録

状態確認:

```text
自動起動の状態確認.bat
```

解除:

```text
WINDOWS自動起動を解除.bat
```

## 注意

PCの電源が切れている間やスリープ中はBOTも停止します。
24時間動かすには、PCを起動したままにするか、
外部サーバーへ設置する必要があります。

## v6 プレゼント企画機能

管理者は次のスラッシュコマンドで企画を作成できます。

```text
/giveaway-create
```

入力項目:

- `prize`：景品
- `deadline`：締め切り日時（例 `2026/08/01 21:00`、日本時間）
- `minimum-level`：参加できる最低レベル

企画パネルには以下のボタンがあります。

- 参加
- 参加取り消し
- 参加者一覧
- 当選確率
- チケットで確率を上げる
- 企画中止（管理者のみ実行可能）

通常は1人1口です。小悪魔チケットを1枚使うごとに抽選口数が1口増えます。
参加取り消し・企画中止の場合、企画に使用したチケットは返却されます。
締め切り後は自動抽選され、当選者へDMが送信されます。

### 更新後に必ず行うこと

`FIRST_SETUP.bat` または `初回セットアップ.bat` を実行し、
新しい `/giveaway-create` コマンドをDiscordへ登録してください。


## シーズン制度
- 日本時間の毎月1日から月末までを1シーズンとして集計します。
- 翌月1日に、設定した専用チャンネルへチャット数・VC時間・総合XPランキングを投稿します。
- 投稿後、レベル・XP・チャット数・VC時間を自動リセットします。小悪魔チケットは減りません。
- 管理者が `/setup-season-channel` で通知先を設定してください。


## v9 チケットショップ

`/ticket-exchange` は `/ticket-shop` に変更されました。

管理者コマンド:
- `/ticket-shop-add` 商品名・必要チケット枚数・説明を追加
- `/ticket-shop-edit` 商品名・必要枚数・説明・表示状態を変更
- `/ticket-shop-remove` 商品を削除
- `/ticket-shop-list` 商品IDと設定を確認

メンバーは `/ticket-shop` から商品ボタンを押して交換申請できます。
申請後は本人だけに「交換できた」ボタンが表示され、押すと交換完了記録が専用チャンネルへ送られます。
更新後は `FIRST_SETUP.bat` を実行してコマンドを再登録してください。


## VC XPの獲得条件（v10）
- 同じVCにBOTを除いて2人以上いること
- 自己ミュート・サーバーミュート中は獲得不可
- スピーカーミュート（自己/サーバー）中は獲得不可
- AFK・除外設定VCでは獲得不可
- 基本は5分ごとに10XP
- 条件を満たした連続滞在30分ごとに、5分あたりのXPが1ずつ増加（最大20XP）
- 退出・人数不足・ミュートになると連続滞在ボーナスはリセット


## v11 複数サーバー対応

- スラッシュコマンドをグローバル登録へ変更しました。
- `GUILD_ID` を固定しなくても、BOTを招待したすべてのサーバーで利用できます。
- レベル、XP、チケット、通知チャンネル、ショップ商品、企画はサーバーごとに別々に保存されます。
- 各サーバーの管理者が、通知先などをそのサーバー内で設定してください。

### 別サーバーへ追加する方法

1. `BOTを招待.bat` を実行します。
2. 追加したいサーバーを選択して認証します。
3. 初回更新時だけ `FIRST_SETUP.bat` を実行して、全サーバー共通コマンドを登録します。
4. 追加先サーバーで `/setup-level-notify`、`/setup-exchange-channel`、`/setup-season-channel` を設定します。

`.env` に必要なのは次の2項目です。

```text
DISCORD_TOKEN=BOTトークン
CLIENT_ID=アプリケーションID
```

`GUILD_ID` は通常不要です。旧版のサーバー専用コマンドを消す場合だけ、以前使っていたサーバーIDを一時的に入れてセットアップを実行できます。

グローバルコマンドはDiscord側への反映に少し時間がかかる場合があります。


## 入室・退出通知

管理者が `/setup-join-leave-channel` を実行して通知先チャンネルを指定すると、
メンバーがサーバーへ参加した時に「📥 入室」、サーバーから抜けた時に「📤 退出」を自動表示します。

### 必須設定
Discord Developer Portal → Bot → Privileged Gateway Intents で **Server Members Intent** をONにしてください。
OFFのままだと入室・退出イベントを受信できません。

設定後は `コマンド重複を修正.bat`（または `npm run register`）を一度実行して新しいコマンドを登録し、BOTを再起動してください。


## 🔰 初心者ヘルプ案内パネル
管理者は `/setup-beginner-help` を実行し、設置先チャンネルを指定すると初心者向けの常設パネルを設置できます。
パネルには「サーバーの使い方」「レベル」「チケット」「ショップ」「ギフト企画」「シーズン」「困ったとき」のボタンがあり、押した本人だけに説明が表示されます。

## v14: 三重・多重起動対策

古いバージョンのBOTや自動起動ランチャーが残っている場合は、最初に `旧BOTを完全停止.bat` を1回実行してください。
その後、`BOT起動.bat` は1回だけ実行してください。
新版本体には単一起動ロックがあるため、同じ新版を2回起動しようとしても2個目は終了します。
